# Guia Lara

Directorio local de servicios para Barquisimeto, Lara, Venezuela.

Esta es una primera version hecha con HTML, CSS y JavaScript.

## Archivos principales

- `index.html`: pagina principal.
- `styles.css`: diseno visual.
- `app.js`: buscador, categorias y formulario.
- `assets/hero-barquisimeto.png`: imagen principal.
- `guia-paso-a-paso.md`: explicacion para aprender el proyecto.
